Apple Player 1.0.0 — первый выпуск

- Светлый интерфейс в духе Apple с розовым акцентом и обложками альбомов.
- Локальная медиатека MP3: файлы, папки с подпапками, перетаскивание.
- Название, исполнитель, альбом и обложка из ID3v2.3/2.4.
- Поиск и избранное, пауза, перемотка, громкость, переход между треками.
- Повтор одного трека / всех треков и случайный порядок.
- Сохранение библиотеки, избранного, режимов и громкости.
- Переносимый EXE и установщик без прав администратора.
- Регистрация в списке приложений для MP3; выбор плеера по умолчанию подтверждается в параметрах Windows.

Проверено на Windows 11: 28 функциональных проверок с синтетическим MP3, а также установка, работа установленного приложения, повторная установка и удаление с сохранением пользовательского файла. Субъективное качество звука автоматическими проверками не оценивается.
