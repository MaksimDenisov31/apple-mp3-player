Apple MP3 Player 1.1.0 — тёмная тема и новое название

- Основной исполняемый файл: AppleMP3Player.exe; совместимая копия прежнего имени сохраняется в установленной версии.
- Название приложения изменено на Apple MP3 Player: окно, ярлыки, установщик и отображение в приложениях Windows по умолчанию.
- Переключатель светлой и тёмной темы справа в заголовке окна. Выбор сохраняется между запусками.
- Тёмная палитра охватывает медиатеку, поиск, нижнюю панель, меню, подсказки, прокрутку и подтверждение очистки.
- Медиатека, избранное, размеры окна и назначение плеером по умолчанию сохраняются. Для обновления используется прежняя папка установки.

Проверено: 97 функциональных проверок, обе темы, сохранение темы и размеров после перезапуска, воспроизведение шести форматов. Проверены установка, обновление отображаемого имени и удаление с сохранением пользовательского файла и прежних приложений по умолчанию.
