Apple Player 1.0.3 — плеер по умолчанию и очистка медиатеки

- На последнем экране установщика предлагается сделать Apple Player плеером по умолчанию. При завершении открывается нужная страница настроек Windows, где пользователь подтверждает выбор.
- Кнопка «Плеер по умолчанию» в самом приложении.
- Поддержка и регистрация MP3, WAV, M4A, AAC, WMA и FLAC; кодеки воспроизведения предоставляются Windows.
- Кнопка «Очистить медиатеку» с подтверждением в стиле приложения: убирает все треки и избранное, останавливает воспроизведение, сбрасывает поиск, обложку и историю. Музыкальные файлы и настройки громкости/режимов остаются.
- Очистку можно отменить кнопкой или Esc. Незавершённый импорт после очистки не возвращает старые треки.
- Сборка не требует закрытия запущенного переносимого плеера.

Проверено на Windows 11: 76 функциональных проверок, включая воспроизведение шести форматов и очистку медиатеки. Также проверены установщик, регистрация форматов, сохранение прежнего выбора приложений по умолчанию, обновление и удаление с сохранением пользовательского файла.
