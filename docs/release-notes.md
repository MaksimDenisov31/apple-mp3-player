Apple MP3 Player 1.1.1 — единое имя проекта

- Папка проекта и основной EXE теперь называются Apple MP3 Player и Apple MP3 Player.exe, с пробелами.
- Обновлены сценарии сборки, ресурсы, пространство имён кода, установщик, ярлыки, пути настроек и документация.
- Прежняя медиатека при первом запуске копируется в новую папку данных. Сохраняются треки, избранное, тема, громкость и размеры окна. Исходные данные не удаляются, новые настройки не перезаписываются.
- Новый EXE работает с существующими ассоциациями Windows благодаря перенаправлению прежних команд открытия. История репозитория и прежние выпуски сохранены при переименовании GitHub-репозитория.

Проверено: 103 функциональные проверки, включая миграцию данных, запуск из пути с пробелами и обе темы. Проверены установленный EXE, команды открытия, совместимость прежних ассоциаций, обновление и удаление с сохранением пользовательского файла.
