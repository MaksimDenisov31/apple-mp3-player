# Проверка 1.0.0

Дата: 18 ноября 2026 года. Среда: Windows 11 x64, .NET Framework 4.8, Inno Setup 6.7.1.

Успешно выполнены 28 функциональных проверок (`tools/Verify.ps1`): синтетический настоящий MP3, ID3 с кириллицей, встроенная обложка, пустая библиотека, импорт и исключение дубликатов, второй файл, поиск, избранное и фильтрация, открытие декодером, длительность, продвижение позиции, пауза, перемотка, возобновление, следующий/предыдущий трек, повтор одного/всех треков, случайный порядок, остановка в конце, сохранение/чтение состояния, снимок интерфейса, безопасное удаление из медиатеки, воспроизведение оставшегося файла, повреждённые теги и настройки.

Успешно выполнены проверки установщика (`tools/VerifyInstaller.ps1`): установка в отдельную папку, совпадение SHA-256 установленного EXE, полный функциональный прогон установленного приложения, повторная установка с сохранением тестового пользовательского файла, удаление приложения с сохранением этого файла. Тестовый установщик использует отдельный AppId; ассоциации MP3 и ярлыки в тестовом режиме отключены.

Проверено отображение окна по сохранённому снимку. Прослушивание человеком, тестирование всех вариантов MP3 и отдельный запуск на Windows 10 не выполнялись. EXE и установщик не подписаны цифровым сертификатом.
