# Проверка 1.1.1

20 ноября 2026 года. Повторно выполнены 103 функциональные проверки. Папка проекта, EXE и пути установщика содержат пробелы. Проверены новое имя исполняемого файла, чтение прежней библиотеки, перенос музыки/избранного/темы/громкости/геометрии, сохранность исходной библиотеки и резервной копии, повторный запуск без перезаписи новых настроек и новая папка данных при чистой установке.

Установщик использует новый зарегистрированный идентификатор приложения и корректно заключённую в кавычки команду открытия. На изолированном прежнем ProgID проверены перенаправление на новый EXE и удаление устаревшего отображаемого приложения из списка настроек. UserChoice не переписывается. Проверены полный функциональный прогон установленной версии, повторная установка и удаление с сохранением пользовательского файла.
